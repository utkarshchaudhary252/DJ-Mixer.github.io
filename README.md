# 🎧 Virtual DJ Mixer

A **Python-based desktop DJ Mixer** that simulates a dual-deck DJ setup for playing and mixing MP3 audio files.

## ✨ Features

* 🎵 Dual MP3 players with separate playlists
* ▶️ Play, Pause, Previous & Next controls
* 🔊 Volume control for each deck
* 🎚️ Bass, Mid & Treble equalizer
* 🎛️ Multiple built-in EQ presets
* 🔀 Shuffle & Repeat support
* ⏩ Track seeking and progress display
* 📊 Visual VU meters
* 🎚️ Equal-power crossfader
* 🖥️ Interactive Tkinter GUI

## 🛠️ Technologies

* **Python**
* **Tkinter** – GUI
* **python-vlc** – Audio playback
* **VLC Media Player** – Media engine

## ⚙️ Installation

Install Python dependencies:

```bash
pip install python-vlc
```

Also install **VLC Media Player** on your system.

## ▶️ Run

```bash
python virtual_dj_mixer.py
```

Load songs into **Player 1** and **Player 2**, adjust the EQ and volume, and use the **crossfader** to mix between the two decks.
